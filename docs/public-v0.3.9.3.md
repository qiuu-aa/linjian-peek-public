# 掌心窗 v0.3.9.3 · 原生话题小口袋

「陪伴 → 更多陪伴 → 话题小口袋」直接进入 App 内的原生页面。可查看最近 30 天活动，打开某一天查看话题与来源，并打 1–5 星、填写或修改评语。返回列表时保留未保存的评语。

继续使用先前填写的小口袋地址。首次连接时填写自己的 HTTPS 小口袋地址；身份核验沿用掌心窗已有连接，不再要求网页登录。

小口袋服务需配置 `PALM_AUTH_URL` 为受信任掌心窗服务器的 `/api/companion/state?limit=1` 地址。本版原生接口仅提供活动读取与评价修改，不开放导出、删除及 MCP 管理权限；只支持明确绑定一个口袋所有者的部署。

版本号：`0.3.9.3` / `30903`。沿用固定签名，可覆盖安装。
